# 视频扩展位置

此目录预留给视频收包、组帧、解码和播放状态。目前只有说明文档，不是 CMake target，也不要求安装 FFmpeg；主界面的“业务工作区”为后续添加视频画面预留位置。

RM26 的 `VideoReceiver`、H.264/HEVC 解码器及视频控件可供参考。接入时建议保留以下边界：

```text
视频数据源 → 收包/组帧 → 解码 → 拥有明确所有权的帧 → Qt Quick 展示
```

- 用独立 `rm27_video` target 管理所需依赖，避免让配置、领域模块链接 FFmpeg。
- UI 选择如何显示画面，不管理 socket 或解码器；领域状态不保存视频解码实现。
- 明确区分“正在收包”“已解码”和“已呈现”，不要用单个连接标志替代各阶段状态。
- 解码等耗时工作移入 worker；跨线程传递帧时约定所有权，限定队列容量，避免延迟和内存持续增长。
- 停止或切换视频源时回收旧会话，关闭后不再向已销毁对象回调。

先完成一条可用视频链路，再按实际需求增加多路视频、录制或回放功能。
