# 协议扩展位置

此目录预留给本赛季协议定义、编解码和协议版本说明。目前只有说明文档，不是 CMake target，也不要求安装 Protobuf。

RM26 的 `src/network/Protocol.*` 和 `src/network/proto/` 可以作为实现方式参考。2026 年的消息编号、topic、字段和频率不能直接视为 2027 年协议；实现前应确认本赛季资料及团队采用的版本。

接入第一条真实消息时：

1. 记录消息方向、传输方式、标识、字段含义和对应资料版本。
2. 把 schema 和编解码放在本目录，建立 `rm27_protocol` target；只有需要协议的模块链接它。
3. 由传输实现接收字节并调用协议编解码，再向应用层提交类型明确的数据。
4. 领域对象和 QML 不包含生成的协议类型，也不解释原始 payload。

如果客户端与独立 Python 模拟器都采用 Protobuf，应从同一份 schema 生成两端代码，并记录生成命令和依赖版本。先实现所需消息，不在骨架阶段复制整套历史协议或声明尚未具备的兼容能力。
